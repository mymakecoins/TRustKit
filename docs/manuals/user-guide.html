Guia do Usuario TRustKit

Manual Oficial de Operacao, Governanca de Spec-Driven Development (SDD) e Execucao Deterministica de Agentes.

1. Introducao e Principios Fundamentais

O TRustKit e um motor deterministico escrito em Rust focado em governanca estrita de SDD, isolamento em Git Worktrees, Gauntlet Loop V2 e inteligencia sintatica via Tree-Sitter.

Invariantes Constitucionais Inviolaveis:
  • Zero Emojis: Absoluta proibicao de icones ou caracteres graficos em codigo, documentacao, commits ou terminais.
  • Zero Trailers de IA: Bloqueio formal de assinaturas automaticas de autoria (como Co-Authored-By).
  • Determinismo Puro: Todas as mutacoes de ciclo e selos de artefatos devem ser conduzidas pelo binario trustkit.
  • TDD Estrito: No Gate 4, a comprovacao da fase RED (falha do teste) e compulsoria antes da fase GREEN.
  • Pull Request Sob Demanda: Abertura de PR somente mediante solicitacao humana explicita.
  • Protecao de Branches: Proibicao de pushes diretos a branches protegidas (main, staging, develop).

2. Planejamento Previo de Marcos (trustkit milestones)

O modulo de planejamento de marcos analisa conjuntamente o PRD e o ADR, mapeia capacidades de negocio e restricoes tecnicas, calcula a ordenacao aciclica (DAG) e gera os arquivos individuais em docs/milestones/ com citacoes exatas de linhas (#LXX-LYY).

Analise e Planejamento (trustkit milestones plan)

# Planeja marcos aciclicos com base em PRD e ADR
trustkit milestones plan --prd docs/PRD_TRustKit.md --adr docs/ADR_001_TRustKit_Architecture.md

# Saida estruturada em JSON sem campos nulos
trustkit milestones plan --prd docs/PRD_TRustKit.md --adr docs/ADR_001_TRustKit_Architecture.md --json

Listagem de Marcos (trustkit milestones list)

# Lista todos os marcos cadastrados no SQLite WAL
trustkit milestones list

# Listagem formatada em JSON
trustkit milestones list --json

Inspecao Detalhada de Marco (trustkit milestones inspect)

# Inspeciona capacidades, restricoes e citacoes exatas do marco M01
trustkit milestones inspect M01

# Inspecao em formato JSON
trustkit milestones inspect M01 --json

3. Inicializacao do Ciclo SDD (Gate 0)

O Gate 0 valida identidade, estado da arvore Git e cria a sessao transacional de ciclo no SQLite WAL.

Inicializacao Direcionada por Marco (trustkit init --milestone)

trustkit init --milestone docs/milestones/M01-fundacao.md

Inicializacao Nominal Vinculada a Issue (trustkit init --issue)

# Inicializacao com issue remota
trustkit init --issue 42

# Inicializacao sem issue vinculada (modo puramente local)
trustkit init

Diagnostico, Status do Ciclo e Orientacao Contextual (trustkit status / NextStepResolver)

Todos os comandos do TRustKit e o diagnostico trustkit status executam o resolvedor contextual deterministico (NextStepResolver), apresentando o rodape padronizado NEXT STEP: em modo ASCII (com prioridades [PRIMARY], [SECONDARY] e [OPTIONAL]) e o array next_steps livre de null em modo --json.

trustkit status
trustkit status --json

4. Modo Autonomo de Ponta a Ponta (trustkit auto)

Executa de forma autonoma e desatendida todo o ciclo do Gate 0 ao Gate 6 com isolamento de worktree e auto-merge final:

# Executa ciclo completo a partir de uma issue remota
trustkit auto --issue 42 --target develop

# Executa ciclo completo a partir de arquivo de especificacao local
trustkit auto --spec docs/specs/042-feature/spec.md --target develop

# Execucao com selecao explicita de runtime de terminal (auto, pty, native)
trustkit auto --issue 42 --runtime pty

5. Jornada Passo a Passo dos 7 Gates

Gate 1: Context Slicing e Linting de Especificacao

# Gera prompt rico com fatiamento de contexto AST e busca semantica FTS5
trustkit spec prompt --idea "Modulo de autenticacao JWT" --context-hops 2 --budget 4000

# Executa linter estatico imediato (< 3ms) para auto-correcao
trustkit spec lint --file docs/specs/042-feature/spec.md

Gate 2: Selamento Criptografico (trustkit spec lock)

trustkit spec lock --spec docs/specs/042-feature/spec.md

Gate 3: Decomposicao Atomica e DAG (trustkit wave plan)

trustkit wave plan
trustkit wave plan --json

Gate 4: Execucao em Git Worktrees e TDD Estrito

# Despacha a onda de tarefas em worktrees efemeras
trustkit wave run --wave 1 --runtime auto

# Registro mandatorio da fase RED (falha comprovada)
trustkit task test TASK-001 --phase red

# Registro mandatorio da fase GREEN (sucesso comprovado)
trustkit task test TASK-001 --phase green

# Revisao semantica multi-angulo do diff da tarefa
trustkit task review TASK-001 --effort medium

# Conclusao e homologacao da tarefa atomica
trustkit task complete TASK-001 --code-review medium

Gate 5: Gauntlet V2 e Invariantes

# Camada 0: Auditoria estatica AST em microssegundos (anti-cheat e invariantes)
trustkit gauntlet ast-audit

# Execucao completa do swarm de criticos e testes E2E Playwright
trustkit gauntlet run

# Execucao com revisao de seguranca de aplicacao forcada
trustkit gauntlet run --security-review

# Diagnostico de falhas ou circuit breaker
trustkit doctor

Gate 6: Certificacao, Merge e Pull Request

# Certifica a conclusao e compila o gauntlet-report.md
trustkit done

# Merge deterministico na branch de destino
trustkit merge --target develop

# Abertura de Pull Request sob demanda explicita
trustkit pr --target develop

6. Auditoria de Seguranca Pre-Release (trustkit audit security)

Auditoria global em 6 fases para homologacao de marcos de versao antes do merge em branches estaveis:

# Auditoria defensiva no perfil padrao
trustkit audit security --profile standard --scope .

# Auditoria em profundidade com emissao de relatorio estruturado JSON
trustkit audit security --profile deep --output-dir .trustkit/audits/security --json

7. Memoria Perene e Base de Conhecimento (trustkit memory)

Gestao de wiki viva em .trustkit/wiki/ indexada em SQLite FTS5 com busca semantica BM25:

# Busca semantica na base de conhecimento
trustkit memory search --query "diretrizes de arquitetura" --limit 5

# Leitura estruturada de nota
trustkit memory read --slug "arquitetura-hexagonal"

# Criacao de nota atomica com tags
trustkit memory write --slug "padroes-de-api" --title "Padroes de API" --tags "api,rest" --body "Texto..."

# Listagem de todas as notas catalogadas
trustkit memory list

# Reconstrucao completa do indice FTS5 a partir dos arquivos
trustkit memory reindex

8. Inteligencia de Grafo Estrutural (trustkit graph)

Mapeia dependencias entre nos de codigo e wiki via Tree-Sitter, com prevencao Shrink-Guard:

# Constroi ou atualiza o grafo estrutural
trustkit graph build

# Diagnostica acoplamento e localiza God Nodes
trustkit graph health --top-god-nodes 10

# Caminho minimo entre dois simbolos via BFS
trustkit graph path --source "src/lib.rs::SddCycle" --target "crates/trustkit-db::SqliteWalRepositoryAdapter"
